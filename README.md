# 📝 ToDo App

A simple and responsive ToDo App built with **React.js**. Easily add, delete, and manage your daily tasks.

## ✨ Features

- Add new tasks
- Delete tasks
- Responsive design

## 🚀 Tech Stack

- React.js
- tailwind CSS

## 📦 Getting Started

# bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
npm install
npm run dev
